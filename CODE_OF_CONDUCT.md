# Code of conduct

This project is a place to build software. Everyone taking part in its issues, discussions,
pull requests and chat is expected to:

- Argue about the work, not the person. Disagree with reasons.
- Be patient with newcomers and with people writing in a second language.
- Keep it on topic. Price talk, promotion of other projects and solicitation belong elsewhere.
- Not harass, threaten or demean anyone, or publish anyone's private information.

Maintainers may edit or remove contributions that break these rules and may block people who
keep breaking them.

To report a problem, write to founder@internetmoneynetwork.org. Reports are kept private.
