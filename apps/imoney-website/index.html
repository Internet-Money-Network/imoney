Money for the internet that a shop can check for itself.

Internet Money is an open-source proof-of-work currency built for payments. Blocks arrive about every five seconds, and the network is kept small enough that a merchant can run a full node and verify every payment without a payment processor in between.

§2Why build it

Three decisions, each made for the person taking the payment.

  1. A node small enough to run yourself

    Fast chains produce so much data that shops end up trusting someone else's API. At one block every five seconds the chain grows slowly, so a merchant can keep a verifying node on an inexpensive server and ask it directly whether they were paid.

  2. Parallel blocks are merged, not thrown away

    When two miners find a block at the same moment, a plain chain discards one. The GHOSTDAG protocol keeps both and puts them in a single agreed order, which is what lets the block time be short without wasting honest work.

  3. Mining bound by memory, not by custom chips

    The proof of work is called Hallmark. It is FishHash, the memory-hard algorithm built for Iron Fish, with a seed of our own. Every hash makes random reads across gigabytes of memory, the thing consumer graphics cards already do well. That limits what custom chips can gain; it does not rule them out.

§3For merchants

Take a payment with a few lines of code.

Every order gets an invoice number that the payer's wallet signs into the payment, so your node can tell you exactly which order was paid and how settled it is. Funds go straight to an address you control. Nobody holds them on the way.

  • SDK for the browser and Node.js
  • WooCommerce plugin for WordPress stores
  • No intermediary fee; the network fee is a fraction of a cent

Both are in development and run against the test network only. Do not use them for real orders yet.

checkout.js@imoney/sdk
// Talk to a node you run
const client = new IMoneyClient({
  nodeUrl: 'http://127.0.0.1:18556'
});

client.openCheckoutModal({
  merchantAddress: 'imntest:q...',
  amountImn: '12.5',
  invoiceId: 'INV-1042',
  level: 'included',
  onSuccess: (payment) => {
    markOrderPaid(payment.invoiceId);
  }
});
§4Supply

Every coin is mined. The schedule is fixed in the code.

The reward halves every four years, four times, and then stays at 0.3125 IMN per block for good, so miners are always paid to secure the network. There is no premine and no share for the developers.

§5Where it stands

Not launched. Here is exactly how far along it is.

There is no public network and no coin to buy. Anyone offering IMN for sale today is not us.

Works today

  • Addresses and Ed25519 signatures
  • Blocks carrying transactions, with miner rewards
  • Node with on-disk storage and an HTTP / WebSocket API
  • GHOSTDAG ordering: nodes agree even when blocks conflict
  • Difficulty that adjusts itself to five-second blocks
  • Fees shared between the miner and the node that served the payment
  • Network sync, peer discovery and bans for misbehaving peers
  • Hallmark proof of work (FishHash), verified by nodes from a small cache
  • CPU miner that works for any node
  • Wallet that signs in your browser, with a recovery phrase
  • Invoice numbers with seen, in-a-block and final levels
  • 12-hour finality: older payments cannot be rewritten
  • Pruning, so a shop's node stays small
  • Explorer showing the live block graph

Being built

  • Seed nodes for a public test network
  • Keeping block headers out of memory

Not started

  • GPU miner
  • Public test network
  • Independent security review
