Every feature, and how we compare

How it works, for the technically curious
  • A block every five seconds. When two miners find one at the same moment, both are kept and put in order (GHOSTDAG), so a short block time wastes no work.
  • A full node is small enough for a shop to run on a cheap server and check its own payments, instead of trusting someone else's.
  • Mining uses graphics cards. The algorithm, Hallmark, is FishHash with our own seed: each hash reads randomly across gigabytes of memory.
  • Escrow, trading and tokens are fixed rules every node checks, not contracts anyone can deploy, which keeps them small enough to review.
  • Trades with other chains use hash locks with SHA-256, which Ethereum-style chains can check too.

The details are in the specification and the developer cookbook.

§4For shops

Add it to your shop in minutes.

On WordPress, install the WooCommerce plugin and enter your address. Customers scan a code to pay, and the order is marked paid by itself.

  • No sign-up and no account with anyone
  • The money goes straight to your address
  • The Refund button works as you'd expect
  • For other sites, a few lines of JavaScript

Test network only for now. Don't use it for real orders yet.

checkout.js@imoney/sdk
// Show a checkout for one order
client.openCheckoutModal({
  merchantAddress: 'imntest:q...',
  amountImn: '12.5',
  invoiceId: 'INV-1042',
  onSuccess: (payment) => {
    markOrderPaid(payment.invoiceId);
  }
});
§5Supply

Every coin is mined, on a schedule nobody can change.

The reward halves every four years, four times, and then stays at 0.3125 IMN per block for good, so miners are always paid to secure the network. There is no premine and no share for the developers.

§6Where it stands

A test network is running. Here's how far along it is.

Test coins have no value. There is no coin to buy yet, so anyone selling IMN today is not us.

Works today

  • Nodes on three continents
  • Wallet and explorer on this site
  • Mining with graphics cards, and a mining pool
  • Order numbers, so a shop sees which order was paid
  • Refunds linked to the order
  • Shared wallets that need two people to approve
  • Payments older than 12 hours can never be undone
  • A node small enough for a shop to run
  • Trading, tokens and escrow
  • Subscriptions and savings vaults
  • A desktop app for Windows, Mac and Linux
  • Three rounds of outside security testing

Being built

  • Swaps with Ethereum, in the wallet
  • Encrypted connections for miners
  • A mining pool built for many miners

Not started

  • A full independent audit
  • Swaps with Bitcoin
