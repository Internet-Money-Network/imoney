text sized for each platform's limits. Copy and paste.

Write "Internet Money", two words, both capitalised. Not "InternetMoney", "iMoney" or "IM".
The ticker is always `IMN`, in capitals, without a dollar sign in running text.

### Handles

Use the same handle everywhere. Try these in order and take the first that is free on every
platform you intend to use:

1. `internetmoneynetwork`
2. `imn_network`
3. `internetmoney_imn`

If a platform has a display name separate from the handle, the display name is
**Internet Money**. Register the handle on the main platforms even if you do not plan to
post there yet: it stops someone else posing as the project.

## Type

- **Headings:** Fraunces (a serif). Fallback: Georgia.
- **Figures, code, labels:** JetBrains Mono. Fallback: Consolas.
- Labels in capitals are letter-spaced widely, as on a banknote.

## Using the mark

- Keep clear space around it of at least the width of its first bar.
- Use it on engraver's green or on note paper only.
- Do not stretch it, recolour it, add effects, or redraw it.
- Do not put it beside another project's logo in a way that suggests a partnership.

Others may use the name and mark to refer to the project. See [TRADEMARKS.md](../../TRADEMARKS.md).

## About paragraphs

**Short (about 50 words)**

> Internet Money (IMN) is an open-source proof-of-work currency built for payments. Blocks arrive every five seconds, mining uses ordinary graphics cards, and nothing was mined in advance. A full node is small enough for a shop to run its own, so a merchant can confirm payments without trusting a third party.

**Medium (about 100 words)**

> Internet Money (IMN) is an open-source proof-of-work currency built for one job: paying and being paid. Blocks arrive every five seconds on a BlockDAG, so blocks found at the same moment are kept instead of thrown away. Mining uses the memory-hard Hallmark algorithm on ordinary graphics cards. There is no premine and no developer fee.
>
> Every payment can carry an invoice number signed by the payer, so a shop knows exactly which order was paid and how settled the payment is. A full node is small enough to run on a modest server, so merchants verify payments themselves.
>
> A test network is running. There is no main network yet.

## Status line

Add this wherever there is room, and always when talking about coins or mining:

> A test network is running. There is no main network yet, and test coins have no value.

## What to say, and what not to

| Say | Not |
| :--- | :--- |
| "About five seconds to be in a block" | "Instant" or "5-second settlement" |
| "Final after about five minutes by default" | "Irreversible in seconds" |
| "No premine, no developer fee" | Anything about price, returns or investment |
| "Designed for graphics cards" | "ASIC-proof" |
| "Open source, publicly reviewed" | "Audited", until a named firm has done one |
| "A network fee under a cent" | "Free" or "zero fees" |
| "A test network is running" | "Launched" or "live", until there is a main network |

Never promise a price, a listing, or a date that has not been announced. Never ask anyone to
send coins, connect a wallet or share a key. The project will not do that, and saying so
plainly helps people spot impersonators.
