# Internet Money name and logo policy

The code in this repository is open source under the licences named in the README. This policy
is about something different: the **name** and the **logo**. Licences to the code do not include
any right to them.

> **Status.** "Internet Money", "IMN", "Hallmark" (as the name of this project's proof of
> work) and the Internet Money logo are used by the Internet Money project as its marks. This
> document states how the project asks others to use them. It is not a claim that any of them is
> registered in any country; registration is a separate legal step.

## Why this exists

Anyone may copy, change and run this code, including to start a different network. What nobody
else may do is make people believe their network, coin, wallet or company is this one. People
who send money need to be able to tell which network they are on.

## What you may do without asking

- Say truthfully that your product works with, runs on, or is built from Internet Money.
  Examples: "accepts Internet Money (IMN)", "IMN wallet", "a mining pool for Internet Money".
- Use the logo, unmodified, to show that you accept or support IMN: on a checkout page, an
  exchange listing, a pool page, a wallet's coin list.
- Write about the project, review it, criticise it, and use the name and logo to illustrate that.
- Run nodes, miners, explorers and services for the Internet Money network and describe them as such.

## What you may not do

- Use the name or logo, or anything confusingly similar, for a **different network or coin**.
  If you fork the code and change the genesis block or the consensus rules, it is a new network
  and needs its own name, ticker and logo.
- Present your product, company or service as the official one, or as endorsed by the project,
  when it is not.
- Use the name or logo in your own company name, product name, domain name or social-media
  handle in a way that suggests you are the project.
- Alter the logo, or combine it with other marks so that it looks like a joint brand.
- Use the marks with anything unlawful, deceptive, or designed to take people's money by
  misleading them.

## Forks

Forking is welcome and is what the code licences are for. A fork that stays on the same network
and follows the same consensus rules is simply another implementation and may say so. A fork
that becomes its own network must:

1. choose a different name and ticker that will not be confused with "Internet Money" or "IMN";
2. choose a different address prefix than `imn:` and `imntest:`, so payments cannot be sent to
   the wrong network by mistake;
3. remove the logo and branding from the software, websites and documentation it ships.

It may still say, truthfully, "forked from Internet Money".

## Asking for permission

For anything this policy does not cover, open an issue in this repository describing the use.

## Changes

This policy may be updated. The version in the `main` branch of this repository is the current one.
